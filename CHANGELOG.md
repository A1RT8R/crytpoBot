# Changelog

Все заметные изменения фиксируются здесь. Версии до стабильного релиза могут менять внутренние структуры данных.

## 2.0.0-alpha.4 — Trust Layer

### Точность расчёта
- Неизвестная комиссия вывода больше не трактуется как `0` и не делает маршрут полностью подтверждённым.
- `known_route_only` теперь пропускает только полностью проверенный маршрут: идентичность актива, сеть, доступность ввода/вывода, комиссия и минимальный вывод.
- Добавлен защитный execution buffer (`CONSERVATIVE_EXECUTION_BUFFER_PERCENT`, по умолчанию 0.15%) и отдельный `conservative_profit_usdt`.

### Качество сигнала
- Добавлен объяснимый внутренний индекс качества на основе свежести и синхронности стаканов, проскальзывания, маршрута, ликвидности и устойчивости сигнала.
- В обычной карточке показывается только один спокойный пользовательский статус: `Подтверждено`, `Высокое`, `Хорошее` или `Базовое`.
- Подробные проверки находятся внутри раскрываемого блока и не перегружают основной сценарий.

### Продукт / подписка
- Качество базового результата остаётся общей функцией продукта, а не paywall: это повышает доверие к FREE и конверсию в подписку.
- Расширенная ценность подписки сохраняется за топами, алертами, всеми биржами, подтверждёнными маршрутами, multi-amount, read-only API и будущим AI-разбором.

### Security hygiene
- Из release-пакета удалены runtime `.env`, резервный `.env.save`, SQLite DB, `__pycache__` и macOS metadata.
- `.env.example` больше не содержит реальный Telegram token, admin id или Fernet key.
- Default `ADMIN_IDS` в коде теперь пустой.
